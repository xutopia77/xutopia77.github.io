Features

专为重度 Claude Code 用户打造

开了十个终端并行干活?CCBuddy 把所有会话装进一块面板,状态变化第一时间知道。

⚡

实时事件流

通过 Claude Code Hooks 采集每次工具调用、用户输入与通知,按会话分文件存储 JSONL 日志,面板实时呈现每个会话正在发生什么。

🧠

智能状态机

事件序列驱动状态推断:运行中 / 等待确认 / 等待输入 / 出错 / 已完成 五种状态一目了然,等待确认与出错自动标记未读,绝不漏掉需要你处理的那一刻。

💬

历史会话回放

直接读取 Claude Code 原生会话记录(~/.claude/projects/),以聊天记录形式回放完整对话,只读零侵入,不改动任何原始数据。

📊

用量统计

趋势图 + 环形图直观展示 token 消耗与用量分布,自动刷新周期可调,花的每一批 token 都看得见、算得清。

🔔

任务栏提醒

桌面端支持任务栏角标与窗口闪烁提醒,会话等待确认或出错时即使最小化也不会错过,切回来处理完继续跑。

🌐

中英双语

界面内建中英文切换,桌面端与服务端共用同一套前端,所有视图、状态徽标与图表文案完整覆盖。

How it works

三步接线,零侵入采集

不改 Claude Code 本体、不联网上报,一条 Hook 管道把事件送进面板。

🪝

① Hook 采集

设置页一键安装 Hooks 到 settings.json,ccbuddy-hook 把事件原样落盘

→
📁

② 本地日志

按会话分文件追加写入 ~/.ccbuddy/events/,纯文本 JSONL,随时可审计

→
🖥️

③ 面板呈现

按 mtime 增量解析 + 状态机推断,每会话保留最新 50 条事件,资源占用极低

历史会话视图直接只读 ~/.claude/projects/ 原生记录 · 全程离线,hook 无需联网

Two forms

桌面端 & 服务端,一套前端两种姿势

前后端通过统一 RPC 协议通信,业务代码不接触 Tauri / HTTP 细节 —— 同一个界面,既能跑在桌面上,也能跑在服务器里。

Quick start

两分钟跑起来

克隆仓库 → 构建运行 → 设置页一键安装 Hooks,即可开始监控。

# 1. 克隆并进入项目
git clone https://github.com/xutopia77/ccbuddy.git
cd ccbuddy

# 2. 开发模式运行(需要 Rust 工具链)
npm install
npm run tauri dev

# 3. 首次使用:设置页 → 「一键安装 / 更新 Hooks」
# 1. 构建无头服务端(前端产物嵌入二进制)
cargo build --no-default-features --bin ccbuddy-server

# 2. 启动(首次自动生成随机密码并打印一次)
./target/debug/ccbuddy-server -p 18787

# 3. 浏览器打开 → 登录 → 完成

Hook 优先使用本地文件,否则使用程序内嵌 hook(编译期嵌入),全程无需联网。数据全部留在本机:~/.ccbuddy/

Security

数据不出本机,密码不落明文

监控工具不该成为新的风险面。CCBuddy 从第一天就按这个标准设计。

🔒

Argon2id 哈希

访问密码只存 Argon2id 哈希(内存难解、抗 GPU 爆破),明文不落盘,配置文件被读走也无法还原。

🍪

Session Token

登录签发 HttpOnly Cookie,空闲 15 分钟 / 最长 15 天失效,登录态只存内存,重启即失效。

📵

零外发

无遥测、无上报、不联网。事件日志是本地纯文本 JSONL,随时可以审计或删除。

🏠

数据主权

所有数据都在你自己的机器上:事件流、配置、Claude Code 原生记录,删除即消失。
