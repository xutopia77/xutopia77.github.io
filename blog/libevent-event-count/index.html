libevent内部维护了事件数量的统计信息，这对于监控和调试非常有用。本文分析事件数量的含义和使用方法。

2.1 各类型说明

类型 说明
ACTIVE 当前处于活跃状态的事件数量，即已触发但尚未处理的事件
VIRTUAL 虚拟事件数量，用于内部机制（如定时器、信号等）
ADDED 已添加到event_base的事件总数
