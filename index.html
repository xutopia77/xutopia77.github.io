关于我

你好，我是 xutopia77，一名横跨底层开发与全栈工程的技术人，也是一名在文字里安放思考的写作者。

以 C/C++ 为根基，深耕 Linux 系统编程、底层网络模型与音视频技术落地，精通 WebRTC 实时流媒体传输；同时具备全栈开发能力，熟练使用 TypeScript/Go/Vue/Electron 完成从后端服务到跨端桌面应用的全链路开发。

作为 AI 实践者，专注 AI Agent 多智能体系统设计与 AI 工作流搭建；作为开源创作者，在 GitHub 开源了轻量级 C++ 序列化工具、音视频管理组件等项目。在代码之外，文字是我与世界对话的另一种方式。
